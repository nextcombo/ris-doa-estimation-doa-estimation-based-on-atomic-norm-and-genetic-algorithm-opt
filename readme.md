# [RIS DOA Estimation] DOA Estimation Based on Atomic Norm and Genetic Algorithm Optimization [Accessible via Groups for MATLAB Code]

In traditional direction of arrival (DOA) estimation systems, multiple radio frequency (RF) channels and antennas are required to measure different phases of the arriving signals, which is costly and limited in application. This paper proposes a low-cost DOA estimation system that only requires one transmitting and receiving channel by utilizing reconfigurable intelligent surfaces (RIS). By leveraging the sparsity of targets in the spatial domain, an atomic norm based method is proposed to describe the DOA estimation problem as a sparse reconstruction problem with multiple measurements, which also avoids the off-grid issue in the use of spatial angle discretization methods.Furthermore, to enhance the power concentration of the receiver, an improved genetic algorithm is proposed as an optimization method for beamforming schemes. This method utilizes the actual RIS to optimize the measurement matrix, which can only control a few discrete angles. To improve sparse reconstruction performance, the inter-beamforming coefficients are also considered in the optimization method. Simulation results show that the proposed method has better DOA estimation performance than existing methods.

clc\nclear all\nclose all\n\nt=cputime;\n% Genetic parameter settings\nNUMPOP = 250;% Initial population size, i.e., the number of initial coded individuals\nLENGTH = 16; % Binary encoding length, no need to decode here, directly as a variable.\nITERATION = 50;% Iteration count\nCROSSOVERRATE = 0.7;%Hybrid rate\nSELECTRATE = 0.5;% Selection Rate\nVARIATIONRATE = 0.001;% Variation rate\n\n\nfor c=1:1\n% Initialize the population\npop_0 = unifrnd(0,1,1,NUMPOP);% Randomly generate a series of random numbers between 0 and 1\npop = binaryCoding(pop_0,LENGTH);% Convert a randomly generated number to its binary representation\npop_P = MATRIX_P(pop,LENGTH);  % Convert to measurement vector\n\n% Start iteration\nfor time = 1:ITERATION\n    % Calculate the fitness of the initial population\n    fitness_1 = Fitness_obj(pop_P,LENGTH);\n    % Correct fitness to ensure the final result is different from before\n    if c == 1\n        fitness = fitness_1;\n    else\n        %weight Utilizes the row rank of the newly generated matrix to filter.\n        %weight_cor indicates that the absolute value of the correlation coefficient is greater than 0.3 and it will be removed\n        fitness = weight_cor(valid(1:c-1,:),fitness_1,pop_P);\n    end \n    % Selection\n    pop_P = Select(fitness,pop_P,SELECTRATE);\n    %Encoding\n    binpop = Coding(pop_P,LENGTH);\n    % Cross\n    kidspop = crossover(binpop,NUMPOP,CROSSOVERRATE);\n    % Variation\n    kidspop = Variation(kidspop,VARIATIONRATE);\n    % Decoding\n    kidspop = MATRIX_P(kidspop,LENGTH);\n    % Update the population\n    pop_P = [pop_P;kidspop];\n    %Record the average fitness for each time\n    record(1,time) = mean(fitness);\nend\nfigure(1)\nplot(1:ITERATION,record);\nfigure(2)\n[theta,AF] = graph_p(pop_P(1,:));\nplot(theta,AF);\nvalid(c,:) = pop_P(1,:);\n\nend\ncputime-t\n\n
